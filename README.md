# ScanSphere

> AI-Powered Multi-Page Document Digitization System

## Overview

ScanSphere is an intelligent web application that converts printed documents into editable DOCX files using image enhancement and OCR.

v1.0

## Tech Stack

- React.js
- Tailwind CSS
- FastAPI
- OpenCV
- Tesseract OCR
- PyMuPDF
- python-docx
